# Hoops Training (no points)

Weekly basketball training plan with a built-in Tabata timer, bonus rounds and training stats. No points or rewards.

Upload all 7 files: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, apple-touch-icon.png, README.md

Progress is saved on the iPad only, separately from the points version of the app.
The version shows in the top-right corner, so you can tell when an update has arrived.
